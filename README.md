### 📊 Análisis de datos biomédicos con Python

**Tecnologías:** Python · Pandas · Análisis de señales

Proyecto académico desarrollado durante Tecnolochicas PRO, enfocado en el análisis de señales de ECG y la exploración de relaciones entre parámetros biométricos mediante herramientas de Python.

🔗 [Ver repositorio](https://github.com/JanetSuarez07/Analisis_Datos_Biomedicos-)

### ❤️ BIO_PULSE — Monitoreo de ECG

**Tecnologías:** Python · Flask · HTML · CSS · JavaScript

Proyecto de adquisición, procesamiento y visualización de señales electrocardiográficas, con una interfaz web para observar la señal en tiempo real.

🔗 [Ver repositorio BIO_PULSE](https://github.com/JanetSuarez07/BIO_PULSE)

### ⚡ Monitoreo de señales EMG

**Tecnologías:** Python · Instrumentación biomédica · Procesamiento de señales

Proyecto de monitoreo de señales electromiográficas que integra adquisición de señales y visualización para explorar su comportamiento.
